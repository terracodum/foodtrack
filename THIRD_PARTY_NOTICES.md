# Сторонние компоненты и источники

MIT-лицензия приложения не заменяет лицензии зависимостей. Точные версии зафиксированы в pnpm-lock.yaml; полный текст лицензий распространяется с соответствующими npm-пакетами.

- React, Vite, Vinext, Zod, Lucide и прочие зависимости интерфейса сохраняют лицензии авторов.
- PDF.js / pdfjs-dist использует Apache License 2.0; файлы PDF не передаются в платный AI API для чтения.
- Вендорные скрипты Sites сохраняют включённые LICENSE-файлы, в частности scripts/vite/sites-vite-plugin.LICENSE.
- Данные о продуктах предоставляет Open Food Facts: https://world.openfoodfacts.org/ . База распространяется на условиях ODbL; атрибуция сохранена в интерфейсе. Изображения продуктов не включены в исходники. Учитывайте отдельные условия источника при массовом распространении данных каталога.

В репозиторий не включены персональные PDF, фотографии, реальные резервные копии или заполненный каталог предыдущего пользователя.
