# FoodTrack

Персональная фитнес-база: питание, тренировки, вес и InBody в одном месте. Русский интерфейс, светлая и тёмная темы, установка на Android как PWA.

Два независимых способа запуска:

| Вариант | Вход | Постоянные данные | Для кого |
| --- | --- | --- | --- |
| ChatGPT Sites | Через ChatGPT | Cloudflare D1 + R2 | Хочется развернуть и менять приложение вместе со своим ChatGPT |
| Свой сервер | Пароль владельца | SQLite + папка отчётов | Хочется управлять сервером и данными самостоятельно |

Это приложение для личного использования. Self-hosted версия рассчитана на одного владельца на экземпляр, не на публичную регистрацию клиентов. Для друга нужно поднять отдельный экземпляр. Ни один способ запуска не подключается к чужой базе или сайту.

## Что умеет

- Дневник питания по дням: завтрак, обед, ужин и перекусы; порции, КБЖУ, редактирование и копирование вчерашнего дня.
- Свои продукты, бренды, избранное, поиск и штрихкоды через Open Food Facts.
- Рецепты с ингредиентами и массой готового блюда; расчёт на 100 г.
- Тренировки: упражнения, веса, повторы, длительность, разминка, выполненные подходы, черновики, шаблоны и повтор прошлой тренировки.
- Графики рабочих весов и объёма, предыдущие результаты, таймер отдыха.
- История веса, анкета и редактируемые цели питания.
- InBody: состав тела, графики, оригиналы PDF/фото, импорт показателей из текстовых PDF с проверкой перед сохранением.
- PWA, JSON-экспорт/импорт и приватный доступ.

При первом входе появляется пустая анкета. Возраст, пол, рост и вес не заданы заранее. Цели калорий и БЖУ не применяются без действия пользователя.

## Запуск через ChatGPT Sites

Нужен ChatGPT Work с доступными инструментами Sites; наличие подписки само по себе не гарантирует доступность инструмента.

1. Скачайте [ZIP с исходниками](https://github.com/terracodum/foodtrack/archive/refs/heads/main.zip) и прикрепите его к своему ChatGPT.
2. Отправьте текст из [PROMPT_FOR_CHATGPT.txt](PROMPT_FOR_CHATGPT.txt).
3. ChatGPT создаст новый приватный Site, новую D1 и R2, выполнит миграцию и вернёт адрес.
4. Войдите своим аккаунтом и заполните первоначальную анкету.

Подробности для агента: [docs/CHATGPT_SITES.md](docs/CHATGPT_SITES.md).

## Запуск на своём сервере через Docker

Нужен Docker Compose. Сначала получите исходники:

```sh
git clone https://github.com/terracodum/foodtrack.git
cd foodtrack
```

В каталоге проекта:

```sh
cp .env.example .env
```

Откройте `.env`, задайте собственный длинный пароль в `FOODTRACK_PASSWORD`. Для локального запуска оставьте `PUBLIC_URL=http://localhost:3000`. Затем:

```sh
docker compose up -d --build
```

Откройте `http://localhost:3000`. Вход — по заданному паролю. Записи и файлы хранятся в постоянном Docker volume `foodtrack_data`, независимо от пересоздания контейнера.

Для доступа с телефона через интернет нужен ваш домен и HTTPS reverse proxy; `PUBLIC_URL` должен точно совпадать с адресом в браузере. Пример для Caddy, работающего непосредственно на том же сервере, — [deploy/Caddyfile.example](deploy/Caddyfile.example). Порт приложения в Compose по умолчанию доступен только на localhost сервера. Камера и установка PWA на телефоне требуют защищённого контекста HTTPS.

Подробности, обновление и резервные копии: [docs/SELF_HOSTING.md](docs/SELF_HOSTING.md).

## Запуск без Docker

Node.js 24 и pnpm 11.25.0:

```sh
pnpm install --frozen-lockfile
pnpm run build:selfhost
cp .env.example .env
```

Задайте пароль в `.env`, затем:

```sh
pnpm run start:selfhost
```

SQLite и отчёты будут в `./data`, если не указан `DATA_DIR`.

## Разработка и проверки

```sh
pnpm exec tsc --noEmit
pnpm run build:selfhost
pnpm run test:selfhost
```

Sites-сборка использует отдельный Vinext/Workers entrypoint и актуальные helpers навыка Sites. Для standalone используются Vite и Node HTTP server; Cloudflare и аккаунт ChatGPT не нужны.

Проверки self-hosted API включают вход и cookie, отказ без входа и при поддельных заголовках, CSRF, первую настройку, сохранение, конфликт версий, загрузку/скачивание/удаление файла, сжатие большого журнала и сохранение после перезапуска процесса. Docker-образ в среде подготовки не запускался: здесь недоступен Docker daemon.

## Данные и ограничения

В репозитории нет истории питания, отчётов, паролей, базы, Git-истории или идентификатора чужого сайта. Резервные копии и `.env` никогда не добавляйте в Git.

PDF.js извлекает текст на устройстве пользователя. Сканы и фотографии не распознаются автоматически. Проверяйте извлечённые дату и числа. Фото и оригиналы PDF можно прикреплять отдельно, до 10 МБ на файл.

Расчёты целей и расхода тренировки приблизительные. Это журнал и вспомогательный калькулятор, не диагностика. Расход тренировки не увеличивает автоматически лимит еды.

PWA требует интернета для просмотра и сохранения дневника. Service Worker кеширует только offline-экран и статические иконки, не личные записи или отчёты.

JSON-экспорт содержит записи, тренировки и показатели InBody, но не байты прикреплённых файлов. Оригиналы сохраняйте отдельно или копируйте всё хранилище сервера. Размер JSON ограничен 8 МБ; большие журналы сжимаются gzip. Квоты площадки развёртывания могут отличаться.

Open Food Facts может содержать неполные данные: проверяйте КБЖУ по упаковке. Источники и лицензии зависимостей: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Разработка и обновления экземпляров

Каждый пользователь разворачивает собственный экземпляр и хранилище. Обновления этого репозитория не меняют уже опубликованные Sites автоматически. Для обновления своего Site попросите ChatGPT применить новые исходники к существующему Site, сохранив его project_id, D1, R2 и текущие права доступа. Инструкция создания нового Site применяется только при первом развёртывании. Перед обновлением сохраните JSON и оригиналы отчётов.

GitHub Actions проверяет TypeScript, сборку standalone и HTTP API на Node.js 24 при push и pull request.
